# [Find distinct elements](https://www.geeksforgeeks.org/problems/find-distinct-elements-1614078205/1)
## Easy
Given an array arr[]. Your task is to return the count of all the distinct elements in an array
Examples:
Input: arr[] = [2, 2, 3, 2]
Output: 2
Input: arr[] = [12, 1, 14, 3, 16]
Output: 5
Constraints:1 ≤ arr.size() ≤ 100-1000 ≤ arr[i] ≤ 1000
